# 0001 – Format des décisions
Statut : accepted

## Contexte
On veut tracer les choix avant d'écrire du code.

## Décision
Un fichier Markdown par décision dans `docs/adr/`, numéroté `NNNN-sujet.md`, avec : Statut, Contexte, Options, Décision, Conséquences. Une décision acceptée n'est pas réécrite : on la remplace par un nouvel ADR.
